ABOUT THE PROJECT

About ToolsNova

ToolsNova is a collection of free, browser-based utilities for everyday tasks involving PDFs, images, text and developer data. The aim is simple: useful tools without unnecessary registration or uploads.

Who builds and maintains ToolsNova?

ToolsNova is an independent web project developed and maintained under the ToolNovaHub GitHub account. The project is not presented as an accredited security laboratory or a large software company.

The source repository and project history are available at GitHub: toolnovahub/toolnovahub.github.io. You can inspect the project and report issues there.

How does local processing work?

The browser downloads the site's HTML, CSS, JavaScript and libraries. For supported file and text utilities, the processing then runs on your own device rather than uploading the content to a ToolsNova conversion server.

Local processing is not the same as being fully offline: the website must be loaded, and standard hosting requests still occur. Optional Google Analytics is loaded only if you accept the analytics choice. See the Privacy Policy for details.

Performance and maximum file sizes depend on your device, browser and the individual tool. Some conversions, such as PDF compression, may change document properties or lose selectable text; those trade-offs are documented on the relevant tool page.

What technologies power the tools?

ToolsNova is built primarily with semantic HTML, responsive CSS and JavaScript. Depending on the feature, the tools use browser APIs such as Web Crypto, Canvas and file handling, alongside locally hosted libraries including PDF.js, pdf-lib, JSZip and QR code utilities.

The website is published from a GitHub repository through GitHub Pages. The main website is toolsnova.online; testing or alternate deployment environments are not separate official products.

How are the tools checked?

Development checks focus on representative inputs, the expected output, obvious invalid-input cases and usability on desktop and mobile. For example, a converter should be checked with supported and unsupported formats; a PDF operation should be checked with the resulting file; a text utility should be checked against a known example.

These are practical project checks, not a claim that every browser, device or edge case has been exhaustively tested. GitHub deployment checks confirm publication, but do not replace functional testing. If you find a bug or unexpected output, please report the steps and expected result.

Privacy and transparency

ToolsNova does not require an account for its current tools. Supported input processing happens in the browser, and the site provides choices for optional analytics. Do not assume that any browser-based application can guarantee absolute confidentiality or security in every environment.

For more detail about hosting, files, analytics choices and third parties, read the Privacy Policy.

Contact, feedback and issue reports

For bug reports, reproducible issues, feature suggestions or questions about the project, open an issue in the ToolsNova GitHub issue tracker. Please do not include passwords, private documents or other sensitive information in a public issue.
