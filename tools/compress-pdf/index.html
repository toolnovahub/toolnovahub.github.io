    Compress PDF

    Reduce the size of image-heavy PDFs directly in your browser.

    Best for scanned or image-heavy PDFs. This process converts every page to an image: selectable text, links, forms, bookmarks and accessibility tags are lost. Keep your original. Maximum 20 MB and 40 pages. Processing is local; PDF libraries are served by this website.
    QUICK GUIDE

    How to use Compress PDF

    Choose a PDF and a quality level, then compress. This tool converts each page to an image, so selectable text and links will not be preserved. Keep the original document.

    Privacy first

    Processing happens in your browser. No account or server upload is required.
