    Frequently Asked Questions

    Can I set exact pixel dimensions?

    Yes. Choose the desired width and height using the resize controls.

    How can I avoid stretched images?

    Keep the original aspect ratio when adjusting dimensions, if that option is available.

    Does increasing image size improve quality?

    No. Upscaling adds pixels but cannot recreate missing detail in the original image.

    When should I resize an image?

    Resize large pictures for thumbnails, website layouts or upload dimensions.
